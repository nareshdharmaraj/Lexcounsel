# LexCounsel & JusticeHub - Law Firm Website Templates

Two professional law firm websites with modern glass UI design, parallax animations, dark/light themes, and RTL support.

## 🌟 Features

- ✅ **Two Complete Websites** - Each with unique design themes
- ✅ **9 Pages Total** - Home (x2), About, Services, Contact, Login, User Dashboard, Admin Dashboard, 404
- ✅ **Dark & Light Themes** - Toggle between themes with smooth transitions
- ✅ **RTL Support** - Full right-to-left language support
- ✅ **Glass UI Design** - Modern glassmorphism effects throughout
- ✅ **Parallax Animations** - Smooth scrolling effects and floating elements
- ✅ **Fully Responsive** - Works on all screen sizes (mobile, tablet, desktop)
- ✅ **Modern Tech Stack** - Pure HTML5, CSS3, and Vanilla JavaScript

## 🚀 Getting Started

1. **Open the website**: Simply open any HTML file in your browser
   - `index.html` - LexCounsel home page
   - `index2.html` - JusticeHub home page

2. **Add Images**: Replace placeholder images in the `assets/` folder with your own:
   - Use JPG format as specified
   - Recommended sizes:
     - Hero images: 1200x800px
     - Client photos: 400x400px
     - Attorney photos: 600x600px
     - Office photos: 1000x667px

3. **Customize Content**: Edit the HTML files to update:
   - Company name and branding
   - Contact information
   - Service descriptions
   - Team member details

4. **Customize Colors**: Edit `style.css` to change theme colors:
   - Look for `:root` CSS variables
   - Modify `--primary-1`, `--secondary-1`, etc.

## 🔧 Customization Guide

### Changing Colors
Edit the CSS variables in `style.css`:
```css
:root {
    --primary-1: #6366f1;  /* Change this */
    --secondary-1: #8b5cf6; /* And this */
}
```

### Adding New Pages
1. Copy an existing HTML file
2. Update the navigation links
3. Add your content
4. Link the CSS files: `style.css` and `pages.css`

### Modifying Animations
Edit `parallax.js` to adjust:
- Parallax speed
- Floating card behavior
- Scroll reveal timing
